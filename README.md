# Dynamic Portfolio Web Application

A full-stack, production-ready portfolio web application built with **Django** that showcases my skills, projects, experience, and journey as a developer. Unlike a static portfolio, this application includes a secure admin dashboard that allows me to update content in real time without modifying the source code.

## Live Demo

**Portfolio:** https://portfolio-j3ox.onrender.com

**Deployed on:** Render

## Features

- Secure admin-only authentication
- Dynamic portfolio content management
- Update projects, skills, resume, profile, and about section directly from the admin dashboard
- No code changes required for content updates
- Responsive design optimized for desktop, tablet, and mobile devices
- Interactive skills section with tab-based navigation
- Categories for Languages, Frontend, Backend, Databases, Frameworks & Libraries, AI/ML, and Tools
- Cloud-based media storage using Cloudinary
- PostgreSQL database integration
- Smooth animations and modern user interface
- Cursor-follow tail animation for an enhanced user experience
- Production-ready deployment on Render

## Tech Stack

- **Backend:** Django, Python
- **Database:** PostgreSQL
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Media Storage:** Cloudinary
- **Backend Services:** Supabase
- **Hosting:** Render
- **Version Control:** Git, GitHub

## Project Overview

This portfolio is designed as a fully dynamic web application rather than a static website. It enables complete content management through Django's secure admin panel, making it easy to maintain and update projects, skills, resume, and personal information. The application focuses on performance, responsiveness, and a clean user experience while leveraging cloud services for reliable deployment and media storage.

## Future Enhancements

- Project filtering by technology
- Blog management system
- Contact form email notifications
- Visitor analytics dashboard
